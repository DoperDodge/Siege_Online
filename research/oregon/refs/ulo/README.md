# Your screenshots go here

Drop in-game screenshots of Oregon here, following `research/oregon/SCREENSHOT_CHECKLIST.md`
(file names matter — they're how future sessions find the right shot).

- Images in this repo are stored with **Git LFS** (see `.gitattributes`). On Windows, install
  Git LFS once (`git lfs install`), then `git add` / `git commit` / `git push` as normal.
- This repository is currently **public**. Your screenshots are your own captures for personal
  reference; if you'd rather not publish them, make the repo private first
  (GitHub → Settings → General → Danger Zone → Change visibility).
